## 🔍 ROOT CAUSE ANALYSIS - Why These Issues Exist


### 1. API Key System Issues
**Why:**
- Provider type 'google' missing from ProviderName type
- loadKeysFromProviderStore() missing 'google' -> keys.google = undefined -> gemini routing fails
- Encryption path may fail if safeStorage unavailable on Windows (renderer)
- Base64 fallback may corrupt unicode API keys

### 2. Primary Model Selection Not Working
**Why:**
- assumption that provider-registry.ts config is loaded by front via IPC
- But front may cache old config and not reload after save
- No validation that selected model exists for provider
- No UI feedback when save fails

### 3. Google Models Disappeared
**Why:**
- Google provider type missing + keys.google undefined
- Frontend cache of provider list from old config
- No refresh after saveProviderConfig()

### 4. Ghost Control Not Working
**Why:**
- No IPC handlers exposed in preload
- ghost-control.ts not registered with ipcMain
- User asks but backend never responds

### 5. Voice/Text Interaction Mixed
**Why:**
- chat-handler.ts handles responses
- But voice.ts may be receiving same events
- IPC channels not separated clearly
